# Зелёный патруль

Игра «Змейка», написанная на языке **Goboscript** и компилируемая в проект **Scratch 3 (.sb3)**.

---

## Что скачать для сборки

Для сборки проекта на локальном компьютере понадобятся две бесплатные утилиты:

1. **Python 3** (версия 3.8 или новее) — [python.org/downloads](https://www.python.org/downloads/)
2. **Goboscript CLI** (компилятор кода в Scratch 3):
   * **Windows / Linux / macOS**: Скачайте готовый архив со страницы [Goboscript Releases](https://github.com/aspizu/goboscript/releases/latest) и поместите исполняемый файл `goboscript` в системный `PATH`.
   * Либо через Rust/Cargo: `cargo install goboscript`

> *Дополнительные сторонние Python-библиотеки ставить не требуется — скрипт сборки использует только стандартную библиотеку Python.*

## Структура проекта

* `Stage.gs` — сцена: глобальные переменные, смена фонов и музыка.
* `snake_head.gs` — голова змейки: управление, расчёт движения, перемещение через край, проверка столкновений со своим телом, поедание мусора и штрафы.
* `snake_body.gs` — тело змейки: создание и обновление звеньев-клонов, передача координат по истории, анимация проглатывания мусора.
* `grid.gs` — процедурная генерация шахматного поля (штамповка через Pen `stamp` в режиме без обновления экрана).
* `trash.gs` — мусор (бонусные объекты +1, +2, +3 очка, спавн по сетке).
* `bin.gs` — мусорная корзина (штрафной объект, отнимает 1 очко и 1 звено).
* `score_d1.gs`, `score_d2.gs`, `score_label.gs` — табло и спрайты счётчика очков (десятки и единицы, динамический выбор костюмов без переменных).
* `btn_start.gs`, `btn_settings.gs`, `btn_restart.gs`, `btn_close.gs` — кнопки пользовательского интерфейса.
* `loading_spinner.gs` — анимация экрана загрузки.
* `assets/` — ресурсы проекта:
  * `assets/backdrops/` — фоны (меню, заставка, настройки, загрузка, победа, поражение);
  * `assets/costumes/` — векторные SVG-костюмы спрайтов и плиток поля;
  * `assets/sounds/` — звуковые эффекты и музыка в формате WAV.
* `goboscript.toml` — конфигурационный файл проекта Goboscript.
* `build.py` / `build.cmd` — скрипт сборки двух версий проекта, русификации и добавления блоков-заметок.
* `.github/workflows/build.yml` — конфигурация CI/CD пайплайна для сборки на GitHub Actions при коммитах в ветку `main`.

## Как собрать игру

### Способ 1 (Windows в один клик)
Дважды нажмите на файл **`build.cmd`**.

### Способ 2 (через терминал)
Откройте консоль в папке проекта и выполните:
```bash
python build.py
```
*(или `python3 build.py` на Linux / macOS)*

Скрипт автоматически создаёт **две версии игры**:
1. **`green_patrol_optimized.sb3`** — оригинальная версия, скомпилированная через `goboscript` без перевода, с зарегистрированным расширением `pen` для совместимости со Scratch Desktop.
2. **`ru_green_patrol_optimized.sb3`** — полностью русифицированная версия:
   * Русифицированы имена всех спрайтов, глобальных и локальных переменных, списков, сообщений (`broadcasts`), костюмов/фонов и процедур.
   * Добавлены нативные блоки-заметки (Workspace Comments) с описанием архитектуры и назначения переменных прямо в рабочую область редактора Scratch.

## Как запустить игру

Файлы **`.sb3`** можно открыть:
* В онлайн-редакторе [Scratch](https://scratch.mit.edu/projects/editor/) (меню *Файл* → *Загрузить с компьютера*);
* В [TurboWarp](https://turbowarp.org/);
* В официальном десктопном приложении Scratch Desktop.
